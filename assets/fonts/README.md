# Bundled fonts

The fonts in this directory are bundled with the APK to guarantee consistent
typography without depending on `google_fonts` runtime font fetching.

## Fonts

- `inter/` — Inter (Regular, Medium, SemiBold, Bold)
  - Source: https://github.com/rsms/inter (v4.0)
  - License: SIL Open Font License 1.1 (see `inter/LICENSE.txt`)
- `jetbrains_mono/` — JetBrains Mono (Regular, Medium, Bold)
  - Source: https://github.com/JetBrains/JetBrainsMono (v2.304)
  - License: SIL Open Font License 1.1 (see `jetbrains_mono/LICENSE.txt`)

Both fonts are licensed under the SIL Open Font License, which permits
redistribution and bundling with closed-source applications. Keep the
license files together with the font assets when redistributing.
